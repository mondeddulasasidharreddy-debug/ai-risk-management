# AI Risk Management

A simple AI risk register. Log risks, score them (likelihood x impact), track mitigation and status, view a heat map, and export to CSV.

## Files
- index.html - page structure
- style.css - styling (light and dark mode)
- script.js - logic (scoring, filtering, heat map, CSV export, saving in the browser)

## Run
Open index.html in any web browser. No installation needed.

## Scoring
1-4 Low, 5-9 Medium, 10-14 High, 15-25 Critical.
